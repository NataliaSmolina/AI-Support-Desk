Создал первую таблицу tickets, которая будет использоваться для хранения обращений

| Поле         | Тип данных       | Описание                                                                    |
| ------------ | ---------------- |-----------------------------------------------------------------------------|
| `id`         | `BIGSERIAL`      | Уникальный идентификатор обращения                                          |
| `chat_id`    | `BIGINT`         | Идентификатор тг чата пользователя                                          |
| `status`     | `VARCHAR(20)`    | Текущее состояние обращения: новое, в обработке и т.д.                      |
| `category`   | `VARCHAR(50)`    | Категория обращения                                                         |
| `priority`   | `VARCHAR(20)`    | Приоритет обращения                                                         |
| `confidence` | `REAL`           | Уверенность модели в результате обработки                                   |
| `decision`   | `VARCHAR(20)`    | Решение по обращению: автоматический ответ, черновик или передача оператору |
| `locked_at`  | `TIMESTAMPTZ`    | Время, когда цorker забрал обращение в обработку                            |
| `attempts`   | `INTEGER`        | Количество попыток обработки обращения                                      |
| `created_at` | `TIMESTAMPTZ`    | Время создания обращения                                                    |                                                 |
