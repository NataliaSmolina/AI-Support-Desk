# RAG: результаты проверки на настоящих сервисах

- Начало повторного прогона: 2026-11-15 22:30 (Europe/Moscow).
- Машина: macOS-15.7.4-arm64-arm-64bit.
- LLM: qwen3:8b, Ollama 0.35.1.
- TEI: BAAI/bge-m3, 1024 измерения; конфигурация `evals/tei.rag.yml`.
- Для короткого демо батч TEI ограничен 512 токенами и четырьмя запросами.
- PostgreSQL/pgvector: отдельная БД rag_eval на порту 5436.
- Четыре вымышленных Markdown-статьи индексированы существующим kb-index.
- Поиск точный, top-k=2, порог расстояния не задан.
- Таймаут запроса к модели: 180 с.

## Автоматические проверки

- 93 теста AI-клиентов и eval пройдены; четыре SQL-интеграционных теста запускались отдельно.
- Четыре SQL-теста на настоящем pgvector пройдены: порядок и расстояния, отсечение, пустая база, несовместимая размерность.
- Общий набор проекта имеет три существующих сбоя тестов бота: ожидание старого параметра chat_id и кнопок без тикета. Файлы бота не менялись.

## Прогрев и первый запуск

- Первоначально TEI оставался на прогреве около десяти минут и занимал около 13 ГБ памяти Docker. Индексация в этой конфигурации не прошла.
- После применения конфигурации короткого демо индексация прошла.
- В первом полном запуске два случая завершились ошибкой этапа генерации; третий случай корректно вернул эскалацию при недостатке информации.
- Предыдущий результат сохранён отдельно, без замены успешным повтором: [JSON первого прогона](06-rag-cold-results.json).
