# Эксперимент 4. Воспроизводимая базовая оценка LLM

## Цель

Зафиксировать повторяемую оценку текущей LLM на задачах классификации обращений и генерации ответов. Тот же набор данных и критерии можно использовать позже для сравнения Ollama с vLLM.

## Системы и наборы данных

- LLM-сервер: по умолчанию Ollama из `infra/llm/compose.yml`.
- Клиенты: `LlmClassifier`, `LlmAnswerGenerator` из общей библиотеки `ai-clients`.
- Классификация: 10 фиксированных вопросов из `evals/data/classify_questions.json`.
- Генерация: 3 сценария из `evals/data/generation_cases.json`.
- Прогрев: по одному запросу к классификатору и генератору до измерений; время прогрева отдельно в latency не входит.
- Для Ollama фиксируется версия сервера через `/api/version`; если её получить не удалось, отчёт это отмечает, а прогон не считается успешным.
- Генерация: temperature `0`, лимиты 100 токенов для классификации и 350 для ответа; модель, URL и таймаут берутся из `AISettings`.

## Метрики и критерий результата

Для классификации отчёт показывает точность отдельно для `category`, `priority`, `sentiment`, `wants_human`, число полностью совпавших примеров и среднее время успешного запроса.

Для генерации проверяются:

1. наличие или отсутствие ответа по сценарию;
2. точное множество `source_ids` относительно ожидаемых источников;
3. соответствие флага эскалации ожидаемому результату.

Прогон считается пройденным только при полном совпадении всех полей классификации, прохождении всех сценариев генерации, успешном прогреве и зафиксированной версии Ollama. При несовпадениях отчёт всё равно сохраняется, а скрипт завершается с кодом `1`.

## Запуск на Ollama

Запустить Ollama и модель, если они ещё не запущены:

```bash
docker compose up -d llm llm-pull
```

Затем из корня репозитория выполнить:

```bash
uv run pytest evals/tests/test_llm_baseline.py
uv run python evals/check_llm_baseline.py
```

Скрипт явно использует провайдер `ollama` и записывает отчёт в [04-llm-baseline-results.md](04-llm-baseline-results.md).

## Сравнение с vLLM позднее

При доступном OpenAI-совместимом API vLLM, установить `LLM_BASE_URL` и `LLM_MODEL` на адрес и имя модели, затем запустить те же сценарии:

```bash
LLM_BASE_URL=http://127.0.0.1:8000/v1 \
LLM_MODEL="served-model-name" \
uv run python evals/check_llm_baseline.py \
  --provider openai \
  --output docs/experiments/04-llm-baseline-vllm-results.md
```

Не менять JSON-наборы или критерии между прогонами. Сравнивать точность и задержки нужно с учётом того, что аппаратная среда и серверная версия могут различаться; адрес, модель, провайдер и машина фиксируются в каждом отчёте.
