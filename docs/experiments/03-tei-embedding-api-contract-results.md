# Результаты эксперимента 3: контракт API эмбеддингов TEI

## Автоматические тесты клиента

Команда:

```bash
uv run pytest libs/ai-clients/tests/test_tei.py
```

Результат:

```text
14 passed in 0.09s
```

Проверяются: порядок и количество векторов, пустой ввод, HTTP-ошибка, недоступность TEI, неверная размерность, некорректный JSON, неверный тип вектора, нечисловые и не конечные значения.

## Проверка на реальном TEI

Запуск:

```bash
docker compose up -d tei
uv run python evals/check_tei_contract.py
```

Live-проверка запускалась командой выше, но TEI на `http://127.0.0.1:8081` в момент проверки не был доступен (`ConnectError`). Это не ошибка unit-тестов; реальные характеристики сервиса пока не подтверждены. См. [отчёт live-проверки](03-tei-embedding-api-contract-live-results.md); после запуска контейнера повторный запуск `evals/check_tei_contract.py` обновит его, не затрагивая этот сводный файл.
