# Telegram-бот поддержки

Принимает вопросы клиентов в Telegram. Позже будет сохранять их в базу для worker'а и показывать операторам черновики ответов.

## Как запустить

1. Получить токен у [@BotFather](https://t.me/BotFather) и вписать его в `.env`: `BOT_TOKEN=...`
2. Из корня проекта:

```bash
uv run python -m support_bot.main
```

Остановить — `Ctrl+C`. Тесты: `uv run pytest`.

### Группа операторов (необязательно)

Без неё бот работает, но карточки операторам не отправляет.

1. Создать группу с темами, добавить в неё бота.
2. В нужной теме отправить `/chat_id` — бот ответит двумя строками.
3. Вписать их в `.env` и перезапустить бота:

```
OPERATOR_CHAT_ID=-100...
OPERATOR_THREAD_ID=...
```

## #2 Commit — 2026-10-09

`хэш` бот: ответ на вопрос клиента, карточка операторам с кнопками, /chat_id

### Что сделано

- Бот отвечает «Принято, ищу решение» на любой текстовый вопрос клиента.
- Хендлеры клиента работают только в личке, хендлеры операторов — только в группе.
- На каждый вопрос бот отправляет в группу операторов карточку: вопрос клиента, черновик ответа и кнопки «Отправить» / «Исправить». Черновик пока тестовый — настоящий будет писать worker.
- Команда `/chat_id` в группе подсказывает номера группы и темы для `.env`.
- Кнопки пока не обрабатываются — это следующий шаг.

### Файлы и функции

| Файл | Что внутри |
|---|---|
| `config.py` | `operator_chat_id`, `operator_thread_id` — куда слать карточки (`int \| None`, необязательные)<br>`env_ignore_empty` — пустая строка в `.env` считается «не задано» |
| `texts.py` | `ACCEPTED` — ответ клиенту<br>`FAKE_DRAFT` — тестовый черновик<br>`BUTTON_SEND`, `BUTTON_EDIT` — подписи кнопок<br>`card()` — текст карточки, `chat_ids()` — ответ на `/chat_id` |
| `keyboards.py` | `DraftAction` — данные внутри кнопки: что сделать + кому ответить (`CallbackData`)<br>`draft_keyboard()` — кнопки под карточкой |
| `handlers/client.py` | `PRIVATE_CHAT` — фильтр «только личка»<br>`question` — «Принято» клиенту + карточка в группу |
| `handlers/operator.py` | `GROUP_CHAT` — фильтр «только группы»<br>`chat_id` — номера группы и темы |
| `main.py` | подключён роутер операторов<br>`Dispatcher(settings=...)` — aiogram сам подставляет настройки в хендлеры |
| `.env.example` | `OPERATOR_CHAT_ID=`, `OPERATOR_THREAD_ID=` |
