# Отчётность интернет-магазина

## Назначение

В этом разделе собраны квартальные отчёты аналитиков с еженедельной статистикой по продажам, доставке, возвратам и поддержке. Отчёты нужны сотрудникам, чтобы быстро находить агрегированные показатели и краткие выводы за нужный период.

## Методика

- Неделя считается с понедельника по воскресенье.
- В отчёты попадают завершённые недели; Q4 2026 содержит данные по 31.12.2026.
- Выручка указана в рублях с НДС.
- Средний чек считается как выручка, делённая на количество заказов.
- Средние доли доставки в срок, возвратов, первого ответа и CSAT взвешены по объёму соответствующей недели.
- Средний срок доставки по кварталу взвешен по количеству отправлений в регионах.
- Проценты округлены до одного знака после запятой, CSAT — до двух.
- Данные приведены по фактическим выгрузкам интернет-магазина: OMS, WMS, биллинг, CRM поддержки и отчёты перевозчиков.

## Структура каждого отчёта

1. Исполнительное резюме.
2. Ключевые показатели квартала.
3. Динамика первой и последней полной недели.
4. Структура выручки по категориям.
5. Еженедельные продажи и доставка.
6. Доставка по регионам.
7. Еженедельные возвраты и поддержка.
8. Причины возвратов.
9. Темы и каналы обращений.
10. Краткие выводы, риски и план действий.

## Как отвечать по отчётам

1. Уточнить, за какой квартал или неделю нужны данные.
2. Назвать период и единицу измерения.
3. Для недели найти её в таблице соответствующего квартала.
4. Для квартала использовать блок «Ключевые показатели квартала».
5. Для причин возвратов и нагрузки на поддержку использовать соответствующие таблицы.
6. Не переносить показатели на другие периоды без отдельной выгрузки.
